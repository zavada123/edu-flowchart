# edu-flowchart — тренажер блок-схем

Тренажер блок-схем для уроків інформатики, як Flowgorithm чи FlowRun, але відкритий, для телефона й вбудовуваний. Учень складає блок-схему алгоритму, запускає її покроково й бачить значення змінних, а тренажер перевіряє схему на тестових даних і віддає застосунку результат.

**Демо:** https://zavada123.github.io/edu-flowchart/

## Що вміє

- Блоки з підручників: Початок і Кінець, Дія, Введення, Виведення, Розгалуження, цикл з передумовою, цикл з післяумовою, «Повторити N разів».
- Схема будується сама: учень натискає «+» на стрілці й вибирає блок. Вона завжди правильна (без «спагеті»), і пальцем на телефоні це зручно. Гілка «Так» іде ліворуч, «Ні» — праворуч, як у підручнику.
- Виконання покроково або автоматично: виділено наступний блок, видно змінні й те, що виведено.
- Вирази в шкільному записі: `S = a + b`, `S := a + b`, `Sr = S : 3`, `x // 10`, `a mod 2`, `a ≥ 5`, `a = 0?` (рівність в умові), `x > 0 і y > 0`, `не (a > b)`, `sqrt(x)`, `"Відповідь:", x`. Без `eval`.
- Помилки українською й біля блока: «Змінна «a» ще не має значення», «Ділення на нуль», «Мабуть, цикл ніколи не закінчиться».
- Побутові алгоритми 3–5 класів: дія словами («Підійди до яблуні») нічого не обчислює, а на умову словами («Є яблука?») під час виконання відповідає сам учень кнопками Так / Ні.
- Два типи завдань:
  - **Склади** (`build`): учень складає схему, тести перевіряють, що вона виводить. Можна вимагати розгалуження чи цикл і обмежити набір блоків.
  - **Виконай** (`trace`): схему дано, учень пише, яким буде значення змінної, а потім може виконати схему й перевірити себе.
- Великий режим для молодших класів (`large`).

## Як вбудувати

### React-компонент

Пакет поставляється як вихідний код TypeScript (його збирає Vite або інший бандлер застосунку):

```sh
pnpm add github:zavada123/edu-flowchart#<commit>
```

`edu-flowchart/core` — лише ядро без React: вирази, виконання, перевірка, розкладка схеми. Його можна запускати на сервері, щоб перерахувати оцінку з `report.program`.

```tsx
import { FlowchartTrainer, tasks } from "edu-flowchart"

<FlowchartTrainer
  task={tasks[0]}
  initialProgram={draft}
  onChange={(program) => saveDraft(program)}
  onComplete={(report) => saveGrade(report)}
/>
```

`onComplete` викликається після кожного натискання «Перевірити». `report`:

```json
{
  "taskId": "inf5-average",
  "mode": "build",
  "passed": true,
  "score": 1,
  "tests": [{ "inputs": { "a": 12, "b": 7, "c": 14 }, "passed": true, "expected": [11], "actual": [11] }],
  "issues": [],
  "program": { "blocks": [{ "id": "…", "kind": "input", "text": "a, b, c" }, "…"] }
}
```

На сервері:

```ts
import { checkBuild, tasks } from "edu-flowchart/core"

const task = tasks.find((t) => t.id === report.taskId)
const trusted = checkBuild(task, report.program)
```

### iframe

```html
<iframe src="https://zavada123.github.io/edu-flowchart/?embed=1&task=inf5-average"></iframe>
<script>
  window.addEventListener("message", (e) => {
    if (e.data?.type === "edu-flowchart:result") saveGrade(e.data.report)
  })
</script>
```

## Як описати задачу

Задача — це об'єкт `Task` (`src/core/tasks.ts`):

```ts
{
  id: "inf5-book",
  mode: "build",
  title: "Книжка і сувенір",
  text: "Якщо ціна книжки не перевищує n гривень, купити цю книжку й сувенір…",
  hint: "«Не перевищує» означає «менша або дорівнює»: p <= n.",
  blocks: ["input", "process", "output", "if"],   // які блоки дати; усі, якщо не вказано
  require: ["if"],                                // що має бути в схемі: "if" або "loop"
  tests: [
    { inputs: { p: 100, n: 150 }, output: ["книжка і сувенір"] },
    { inputs: { p: 200, n: 150 }, output: ["книжка"] }
  ]
}
```

Тест може перевіряти виведення (`output`, усі значення по порядку) або значення змінних наприкінці (`vars`). Числа порівнюються з точністю до мільйонних, текст — без регістру, зайвих пробілів і крапки в кінці. Якщо вхідна змінна читається в циклі, її значення задають масивом: `{ x: [3, 5, -1] }`. Відповіді на умови словами задають так само: `{ "Є яблука": [true, true, false] }`.

Задача «Виконай»:

```ts
{
  id: "inf5-trace-loop",
  mode: "trace",
  title: "Значення x після повторення",
  text: "Знайдіть значення величини x після виконання алгоритму…",
  program: { blocks: [ /* схема */ ] },
  questions: [{ inputs: { x: 4 }, ask: "x" }, { inputs: { x: 10 }, ask: "x" }]
}
```

Правильні відповіді не зберігаються в задачі: тренажер обчислює їх, виконуючи схему. Еталонні розв'язки задач «Склади» лежать у тестах (`src/core/check.test.ts`), а не в коді, який завантажує учень. Тести перевіряють, що кожен еталон проходить свою задачу.

Задачі в демо взято з підручників: Бондаренко, 5 клас (§ 19), Корнієнко, 4 клас, Ривкінд, 8 клас (цикли).

